
# LaunchLab Requirements
## What LaunchLab must do
1. A user can create a new feature flag with a name.
A user can turn a flag 
A user can see a list of all flags.
A user can delete a flag.
A user be shown to a percentage of users,for example 20%.
A user can see a simple dashbord with the number of flags.
A user can edit the flags.
